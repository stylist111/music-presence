# SoundCloud Presence

Неофициальный плеер SoundCloud для Windows 10/11 с отображением трека в Discord. Написан на JavaScript и Electron. Расширения браузера и PreMiD не нужны: музыку нужно слушать **в окне этой программы**. Программа не связана с SoundCloud или Discord.

## Первый запуск

1. Установи Node.js LTS с https://nodejs.org (версия 24 или новее).
2. Распакуй проект и открой `start.bat`. При первом запуске устанавливаются зависимости.
3. Открой https://discord.com/developers/applications → New Application. Назови приложение **SoundCloud** (это имя будет показано в Discord).
4. В General Information скопируй **Application ID** и вставь его в окно программы. Создавать бота не надо. Токен и Client Secret не нужны.
5. Открой настольный Discord и разреши публикацию активности в его настройках.
6. В окне плеера включи трек SoundCloud. Подожди до 15 секунд.

Логин SoundCloud необязателен для доступных публичных треков. Вход по email выполняется на сайте SoundCloud внутри окна; внешние всплывающие окна OAuth намеренно заблокированы. Программа не читает пароль или токены Discord.

## Возможности и ограничения

- Название трека, исполнитель, тип активности «Слушает», ссылка на трек.
- Таймер, если сайт предоставляет длительность и позицию.
- При паузе статус очищается при следующем разрешённом обновлении (до 15 секунд).
- Переподключение после перезапуска Discord; свернутое окно продолжает работать.
- Закрытие программы прекращает воспроизведение и отправку активности.
- Это **не** интеграция Spotify: синхронного совместного прослушивания нет.
- Обложки в этой версии нет. Внешние кнопки могут не показываться владельцу профиля в некоторых клиентах Discord.
- Чтение плеера основано на DOM SoundCloud; если сайт изменит классы элементов, потребуется обновить `preload.js`.
- Программа не скрывает другие активности Discord.

## Сборка EXE

```sh
npm install
npm test
npm run dist
```

Сборка выполняется на Windows. Portable EXE появится в `dist/`. В репозитории есть GitHub Actions: после загрузки файлов открой Actions → Build Windows → последний запуск → Artifacts. Скачать артефакт можно после успешной сборки, обычно нужен вход GitHub. EXE не подписан сертификатом.

## Публикация на GitHub

Создай пустой репозиторий `soundcloud-presence` в своём аккаунте и загрузи содержимое папки, включая `.github/workflows/windows.yml`. Или используй GitHub CLI в этой папке:

```sh
git init
git add .
git commit -m "Add SoundCloud Presence desktop player"
gh repo create soundcloud-presence --private --source=. --push
```

Не загружай `node_modules` или `dist` в исходный репозиторий. Application ID хранится отдельно в пользовательской папке программы. Меняется через меню «Программа».

## Проверка

Автоматические тесты проверяют разбор протокола Discord IPC: фрагментацию пакетов, объединённые пакеты, кириллицу и ограничение размера. Полная проверка воспроизведения и статуса требует Windows, доступа к SoundCloud и запущенного Discord. В среде создания такая проверка не выполнялась.

## Архитектура

Изолированный sandbox preload читает только данные нижнего плеера SoundCloud. Main-процесс проверяет отправителя и домен, затем передаёт активность локальному Discord через Windows named pipe. Сторонние сайты не получают доступ к Node.js. Нет HTTP-сервера, учётных токенов или отправки данных на сторонний backend.
